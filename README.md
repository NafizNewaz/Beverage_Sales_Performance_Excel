# Beverage Sales Performance Analytics (Excel Dashboard)

## Overview

This project presents an interactive **Beverage Sales Performance Analytics** report built in Microsoft Excel. It provides insights into revenue, sales trends, and performance across brands, regions, and retailers.

## Project Structure

### 1. Append Query
- Appended 4 Excel datasets into a single dataset for analysis.
- <a href="https://github.com/NafizNewaz/Beverage_Sales_Performance_Excel/blob/main/Retailers.zip">Dataset</a>

### 2. Pivot Table
Created 6 Pivot Tables covering:
- Revenue by beverage brand  
- Revenue by region/state  
- Revenue by retailer  
- Units sold by beverage brand  
- Revenue trend over time  
- Revenue by region and brand combination  

### 3. Dashboard
An interactive dashboard featuring:
-# KPIs: Total Revenue, Total Units Sold, Average Price per Unit  
- Slicers: Retailer, Region/State, Beverage Brand, Month  
- Charts: Line Chart, Bar Chart, Doughnut Chart, Column Chart, 3D Clustered Column Chart
- <a href="https://github.com/NafizNewaz/Beverage_Sales_Performance_Excel/blob/main/Beverage%20Sales%20Performance%20Dashboard.png">Dashboard</a> view

## Tools Used

- Microsoft Excel  
- Power Query (Append)  
- Pivot Tables  
- Data Visualization  

## Usage

Open the Excel file → Navigate to the **Dashboard** sheet → Use slicers to explore insights.
